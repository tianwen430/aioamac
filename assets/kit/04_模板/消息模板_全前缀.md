# 消息模板（全前缀）

> 每个前缀给一份**可直接抄的骨架**。复制后改内容，别改结构。
> 所有路径相对 `{PROJECT_ROOT}`。ID 格式 `{YYYYMMDD-HHmm}-{序号}`。

---

## 人类 → 总控：`[需求]_`

落点：`01_总控\收件箱\[需求]_{ID}.md`

```markdown
# [需求] {标题}

- 需求编号：REQ-{ID}
- 提出：人类
- 优先级：P0 / P1 / P2
- 基线：{权威依据文件路径}
- 代码基线：{code_root 与当前版本}

## 一、背景
现在是什么状态，为什么现在要做。

## 二、目标
一句话说清交付之后什么变了。

## 三、范围（必须实现）
### 1. {模块}
- {可判定的具体要求}

## 四、明确不做
- {防止扩范围}

## 五、验收标准
1. {能直接判真假}
2. …

## 六、约束
- {不许新增依赖 / 不许改存档格式 / 预算上限 …}
```
